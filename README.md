# MODEL 0 — 프로토타입

판타지 세계에 추락한 우주선의 클론 요원이 슈트를 입고 던전을 내려가는 턴제 로그라이크. 현지에서 주운 **기본 무기**에 몬스터의 **부산물**을 부여해 무기를 만들고, 부산물을 **슈트 부위**(몸·팔·다리·감각)에 끼워 방어를 짠다. 레벨업마다 **근력 · 연산 · 외피 회로** 중 하나를 키운다. 구역마다 연료 결정을 모아 우주선을 다시 띄우면 승리.

- 기획서: [design.md](design.md) (규칙·수치·결정 기록의 기준)
- 몬스터 목록: [docs/monsters.md](docs/monsters.md)
- 웹에서 바로 하기 (GitHub Pages, `main` 푸시마다 자동 배포): https://jinha1226.github.io/PROJ_A/
  - 룩데브 데모: https://jinha1226.github.io/PROJ_A/?lookdev

## 실행

```bash
npm install
npm run dev               # http://localhost:5173  (룩데브 데모: /?lookdev)
npm run build             # 타입 검사 + 정적 빌드 (dist/)
npm run sim -- 200        # 헤드리스 봇 시뮬레이션 200판 (승률·명중률·몬스터·무기 지표, sim/out/*.json)
npx tsx sim/trace.ts sim-0  # 한 판 추적 (마지막 로그)
```

타이틀의 **무기 실험실 (테스트)**: 허수아비를 상대로 무기 · 부산물 부여 · ★ · 정예를 바꿔 가며 시험한다 ([T] 편집).

## 지금 들어가 있는 규칙

- **무기**: 기본 무기 9종(단검 · 장검 · 양손 도끼 · 창 · 철퇴 · 방패 · 활 · 원소 지팡이 · 권총), 일반 · 정예(피해 ×1.25). 무작위 옵션 없음.
- **부산물**: 무기에 부여하면 옵션 하나(원소 4종 또는 부위 옵션), 정예·금지 부산물은 **★ 고유 효과**(치명타 조건 23종, 리치 전용 1종 추가 예정)도 붙는다. ★와 맞는 짝 무기면 고유 이름(예: 단검 + 암습자의 = 그림자 바늘). 슈트 칸에 끼우면 장갑 · 체력 · 회피 · 원소 저항(+25%)과 대가(무게 · 반대 원소 약점).
- **전투 공식 v2**: 명중률 = 80% + 3%p × (명중 − 회피), 20~95%. 맞으면 피격 부위(몸 40 · 팔 25 · 다리 20 · 감각 15)의 AC만큼 무작위로 피해를 깎고, 깎은 만큼 그 부위 내구도가 닳는다. 내구도 0 → 부위 파손(불이익).
- **원소**: 화염 → 화상, 냉기 → 둔화 · 빙결, 번개 → 감전. 다른 원소 효과가 남은 적을 치면 반응(증기 폭발 · 플라즈마 · 초전도 · 충돌).
- **소모품**: 체력 플라스크(보급 지점에서 다시 참), 주사제 4종(가속 · 점화 · 경화 · 집중), 기름통.
- **런 구조**: 구역 2개(버섯 동굴 · 불타는 지하 묘지) × (3층 + 보스). 층 사이 보급 지점(수리 + 상점 또는 재련대). 한 층에 오래 머물면 경보 1~3단계(3단계부터 정예 순찰대가 끝없이 온다).

## 화면

3D 모델을 저해상도로 렌더링해 도트처럼 보이게 한다 (1/3 해상도 + 깊이 외곽선 + 색 단계 제한 + 픽셀 격자 카메라). 사람형 마네킹 하나에 종족 · 형태 · 무기를 입혀 모든 캐릭터를 그리고, 애니메이션을 함께 쓴다. HD 모드(`p`)로 바꿀 수 있다.

- 부드러운 시야 감쇠, 벽 투시(주인공·벽 뒤 몬스터), 바닥 데칼(균열 · 얼룩 · 혈흔 · 잔해), 처치 연출(절단 · 피웅덩이), 마우스오버 외곽선
- HUD 테마 3종, DCSS 원문 형식의 로그 문구

## 구조

로직은 렌더링과 분리되어 있고, `GameEvent`만 내보낸다. 렌더러와 HUD는 이벤트와 상태를 읽어 그리기만 한다 (시뮬레이션이 같은 로직을 그대로 돌린다).
