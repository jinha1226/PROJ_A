# MODEL 0 — 프로토타입

기획서: [design.md](design.md). 판타지 세계에 추락한 SF 클론이 몬스터의 부산물을 슈트에 끼우며 내려가는 턴제 로그라이크. 지금은 기획서 "당면 작업" 1단계(세계관·용어 교체)까지 반영됐다.

## 실행

타이틀의 **각인 실험실 (테스트)**에서 허수아비를 상대로 각인 조합과 연쇄를 시험할 수 있다([T] 각인 편집).

```bash
npm install
npm run dev        # 브라우저에서 http://localhost:5173
npm run sim -- 100 # 헤드리스 자동 대전 시뮬레이터 (런 100회)
npm run build      # 타입체크 + 정적 빌드(dist/)
```

## 구조 (로직과 렌더링 분리)

| 경로 | 맡는 일 |
| --- | --- |
| `src/core/` | 순수 TypeScript 게임 로직. 렌더링에 의존하지 않음 |
| `src/core/game.ts` | 행동 비용 스케줄러, 피해 파이프라인, 효과 엔진, 트리거(턴당 3회 상한), AI, 층·경보·보급 지점 |
| `src/core/dungeon.ts` | 층 생성(방 8~12개), 시야, 경로 |
| `src/core/stats.ts` | 부산물 → 능력치 (플레이어·적 공용) |
| `src/core/rng.ts` | 시드 난수 (같은 시드 = 같은 런) |
| `src/data/` | 부산물 43, 무기 8, 각인 22 (조건 = 공격·이동·피격·대기), 액티브 형태 5×원소 4, MODEL 라인 3, 슈트 프레임 2, 신 2, 적 12 + 보스 2. 코드 식별자는 아직 `relic`이며 2단계(무기 분리)에서 바꾼다 |
| `src/render/projr/` | PROJ_R 격자 렌더러를 그대로 가져온 것 (쥬피터헬풍 조명, Quaternius 캐릭터·던전·무기). `sim.ts`는 PROJ_R 로직 대신 쓰는 호환 모듈 |
| `src/render/bridge.ts` | 우리 게임 상태·이벤트 → PROJ_R 렌더러의 GridState·GEvent 어댑터 |
| `src/render/view3d.ts` | 에셋 로드와 렌더러 구동 (main.ts가 쓰는 화면) |
| `public/assets/` | PROJ_R에서 가져온 CC0 에셋 (출처: `public/assets/ART.md`) |
| `src/ui/` | HTML/CSS 오버레이 (행동 순서 바, 부산물 슬롯, 각인, 로그, 모달) |
| `sim/` | 헤드리스 봇 + 시뮬레이터 (`npx tsx sim/trace.ts <시드>`로 한 런 추적) |

로직은 `GameEvent`만 내보내고, 렌더러와 HUD는 그 이벤트와 상태를 읽어 그리기만 한다.

## 구현된 규칙

- 각인 = 행동 조건 4종(공격·이동·피격·대기) + 효과 17종 + 대상 6종. 피해를 주는 각인은 '공격'으로 쳐서 연쇄된다(최대 3단계). 각인·액티브·적이 하나의 효과 엔진을 공유한다.
- 부산물 손상: 몸 부산물(장갑)이 먼저 피해를 받고, 장갑이 바닥나거나 넘친 피해(한 대당 최대 20%)로 손상된다. 손상되면 효과가 절반이고, 보급 지점에서 모두 수리된다. 파괴는 과부하에서만 일어나며 고정 슬롯은 과부하할 수 없다.
- 과부하 4종: 큰 일격, 각인 재발동, 쿨다운 초기화, 즉시 수리. 발밑 부산물과 장착된 부산물 모두 태울 수 있다.
- 원소 잔류와 복합 반응: 증기 폭발, 플라즈마, 초전도, 충돌.
- 부담이 넘치면 부산물이 절전된다. 행동 비용은 DCSS식이고, 경보는 0~3단계(3단계부터 정예 무한 증원). 경험치는 탐험으로 얻는다.
- 신앙 2종(용광로의 신, 녹의 신): 계율과 은총 3단계.
- 보급 지점: 항상 수리, 그리고 보급 상점·개조대·각인 기록기 중 하나가 무작위로 열린다. 구역 2개(버섯 동굴, 불타는 지하 묘지) × (3층 + 보스).
