# 전투 v2 밸런스 기록

시뮬레이션은 고정 시드 `sim-0` ~ `sim-199`로 200런씩 실행했다. `npm run sim -- 200`은 tsx IPC 소켓 권한 오류로 시작하지 못해 `node --import tsx sim/sim.ts 200`으로 동일한 진입 파일을 실행했다.

| 시도 | 변경 | 승률 | 구역 1 보스 전 사망 | 플레이어 명중 | 몬스터 명중 | 장갑 감소 | 오류 |
|---|---|---:|---:|---:|---:|---:|---:|
| 기준 | 전투 v2 수치 적용, 기존 몬스터 피해 배율 | 0% | 98.5% | 72.4% | 70.5% | 21.2% | 0 |
| 1 | 일반 배율 0.40 + 구역 0.10 + 층 0.02, 정예·보스 0.50 | 0% | 97.0% | 71.7% | 71.3% | 20.3% | 0 |
| 2 | 일반 배율 0.20 + 구역 0.05 + 층 0.01, 정예·보스 0.30 | 0% | 96.5% | 71.8% | 69.3% | 19.5% | 0 |
| 3 | 시도 2 + 일시적으로 슈트 회피 8, AC 8/6/6/4 및 몬스터 명중 −1 | 0% | 95.5% | 69.9% | 57.4% | 36.0% | 0 |
| 최종 | 시도 2, 명세 슈트·몬스터 초기값 복구, 종족·무기별 집계 반영 | 0% | 96.5% | 71.2% | 69.6% | 19.0% | 0 |

목표 대비 최종값: 승률 목표 25~40%에 0%; 보스 전 사망 목표 ≤35%에 96.5%; 플레이어 실측 명중 목표 70~85%에 71.2%로 충족. 종류별 평균 공격 시도 수, 플레이어에게 준 피해, 처치 수와 무기별 사용 비율·승률·턴당 피해를 JSON과 콘솔에 집계한다. 최종 데이터에서 무기 평균 피해량이 높은 몬스터를 1~2회 공격으로 처치했으며 일부 강적은 4회 이상이 걸렸다. 피해 배율을 크게 낮춰도 승률·보스 도달률 개선이 작아 목표를 맞추지 못했다. 병목은 1구역 초반의 반복 전투/누적 피해이며, 명세 우선 조정 손잡이만으로 목표에 도달하지 못했다.

JSON 요약은 `sim/out/`의 타임스탬프 파일에 저장된다. 단계별 커밋은 저장소 `.git` 쓰기 금지로 생성되지 않았다 (`.git/index.lock`: Read-only file system).
